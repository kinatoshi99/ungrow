# Ungrow v0.0.1 🌱💀

> Anti-Plant Care Project — helping plants survive their owners.

Ungrow is a deliberately ridiculous open-source experiment. The first release has exactly one job: let **SOMCHAI the Snake Plant** roast its owner.

## What works

- 🐍 SOMCHAI character
- 🔥 `ROAST ME` button
- 🎲 10 randomized Thai roast lines
- 📱 Responsive single-page UI
- 🚫 No AI, no database, no framework

## Run locally

Open `index.html` in your browser. That's it.

You can also serve it locally:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Contribute nonsense

Want to add a roast line? Edit the `roasts` array in `app.js` and open a Pull Request.

Good first contribution ideas:

- Add a new SOMCHAI roast
- Fix Thai wording
- Improve accessibility
- Add a new plant character in a future version
